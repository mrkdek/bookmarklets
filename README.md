# 🔖 Bookmarklets

Коллекция браузерных скриптов-закладок.

Скрипты запускаются через обычные закладки браузера и автоматически загружают актуальную версию с GitHub Pages.

## Инструменты

### ✍️ Типограф

Инструмент для автоматической типографической обработки текста.

**Файл скрипта:**  
`typograph/script.js`

**Актуальная версия:**  
загружается автоматически при каждом запуске закладки.

---

## Структура репозитория

Каждый инструмент находится в отдельной папке:

    bookmarklets/
    ├── typograph/
    │   └── script.js
    ├── another-tool/
    │   └── script.js
    └── ...

Основной исполняемый файл каждого инструмента называется `script.js`.

## Как работают обновления

Код инструментов хранится в этом репозитории и публикуется через GitHub Pages.

Закладка в браузере содержит только небольшой загрузчик. При запуске он получает актуальный `script.js`, поэтому после обновления файла пользователям не требуется заново устанавливать закладку.

Обновление инструмента:

1. Изменить соответствующий `script.js`.
2. Сделать Commit в GitHub Desktop.
3. Выполнить Push origin.
4. GitHub Pages опубликует новую версию.
5. При следующем запуске пользователи автоматически получат обновлённый скрипт.

## Добавление нового инструмента

Для нового bookmarklet создаётся отдельная папка:

    bookmarklets/
    └── tool-name/
        └── script.js

После публикации файл будет доступен через GitHub Pages:

    https://mrkdek.github.io/bookmarklets/tool-name/script.js

Для каждого инструмента используется отдельная браузерная закладка-загрузчик.

## Ограничения

Работа загрузчика зависит от политики безопасности (CSP) открытого сайта.

Некоторые сайты могут запрещать загрузку внешнего JavaScript или сетевые запросы из bookmarklet. На таких страницах удалённая загрузка скрипта может быть недоступна.
