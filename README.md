# Типограф — установка через GitHub Desktop

Эта папка подготовлена для публикации Типографа в публичном GitHub-репозитории.

## 1. Создай репозиторий через GitHub Desktop

1. Открой GitHub Desktop.
2. File → New repository.
3. Name: `typograph`.
4. Выбери удобную Local path.
5. Нажми Create repository.
6. Открой созданную папку через Show in Explorer / Show in Finder.

## 2. Скопируй файл

Скопируй `typograph.js` из этой папки в корень созданного репозитория.

В GitHub Desktop появится изменение. Внизу слева в Summary напиши, например, `Первая версия Типографа`, затем нажми Commit to main.

После этого нажми Publish repository. ВАЖНО: репозиторий должен быть публичным — не включай Keep this code private.

## 3. Получи адрес typograph.js

После публикации репозитория адрес будет иметь вид:

`https://raw.githubusercontent.com/ТВОЙ_ЛОГИН/typograph/main/typograph.js`

Замени `ТВОЙ_ЛОГИН` на свой GitHub-логин.

## 4. Сделай постоянную закладку

Открой `BOOKMARKLET_TEMPLATE.txt` и замени `__RAW_URL__` на адрес из предыдущего шага.

Весь получившийся текст вставь в поле URL/Адрес браузерной закладки. Название можешь оставить `Типограф`.

## 5. Проверка

Открой страницу, на которой обычно используешь Типограф, и нажми закладку. Должен открыться интерфейс Типографа.

## 6. Как выпускать обновления

Дальше закладку пользователям менять не нужно.

Чтобы обновить Типограф:

1. Замени `typograph.js` в локальной папке репозитория новой версией.
2. Открой GitHub Desktop.
3. В Summary напиши кратко, что изменилось.
4. Нажми Commit to main.
5. Нажми Push origin.

После Push новая версия будет загружаться при следующем запуске закладки.

## Настройки пользователей

Кнопка копирования кода закладки внутри Типографа теперь создаёт маленькую закладку-загрузчик с выбранными настройками, а не копирует весь Типограф. Поэтому обновления программы остаются централизованными через GitHub.

## Важно

Не переименовывай `typograph.js` и не меняй имя репозитория после раздачи закладки пользователям, иначе адрес файла изменится.
